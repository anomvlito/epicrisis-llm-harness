FORMATO DE RESPUESTA OBLIGATORIO — cada campo debe tener exactamente la estructura mostrada en "CAMPOS A EXTRAER". Existen 3 tipos de campo:

1) Campo booleano simple:
{
  "nombre_campo": {"valor": true|false, "evidencia": "cita textual o null"}
}

2) Campo booleano con datos adicionales — mismo criterio para "valor"/"evidencia",
   más las claves adicionales solicitadas (usa null si el dato no aparece):
{
  "nombre_campo": {"valor": true|false, "evidencia": "cita o null", "<clave_extra>": ...}
}

3) Campo de dato simple (texto, número u objeto sin booleano "valor"):
{
  "nombre_campo": "texto" | numero | {"<clave>": ...} | null
}

DEFINICIÓN DE VALORES:
- "valor": true  → condición/procedimiento/infección/falla PRESENTE y confirmado en el texto
- "valor": false → condición/procedimiento/infección/falla AUSENTE (negado explícitamente) O NO MENCIONADO en el texto
- "evidencia": cita textual exacta del fragmento relevante cuando valor es true | null cuando valor es false
- Claves adicionales y campos de dato simple: el valor extraído tal como aparece en el texto, o null si no se menciona
